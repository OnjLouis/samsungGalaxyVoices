Samsung Galaxy Voices

Samsung Galaxy Voices makes compatible Samsung speech voices available locally through NVDA. Once a voice has been installed, speech works offline without a phone, virtual machine, system-wide installation, or continuing network connection.

Important Notice

This is an independent, unofficial project. It is not affiliated with, endorsed by, or supported by Samsung. Samsung owns its speech engines, voice data, product names, and related components.

The add-on contains no Samsung engine or voice files. It downloads a selected package directly from Samsung only after the user gives permission. Availability can vary by language, region, device profile, or changes made by Samsung. Users are responsible for ensuring that their use complies with the terms and laws that apply to them.

First Run

After installation, NVDA offers to open the Samsung Galaxy Voices settings panel. Choose at least one voice and select Download or update. Before the first download, the add-on explains what will be stored and asks for confirmation.

The add-on does not appear in NVDA's synthesizer list until a complete voice and its matching engine have been validated. Successfully downloaded voices become available immediately without restarting NVDA.

Voice Manager

Open NVDA Settings and choose Samsung Galaxy Voices. Installed voices appear first. Original-generation and newer Galaxy S24 premium voices follow as separate choices, so matching languages and voices can be installed side by side. Samsung's smaller classic voices are grouped afterward and identified as Compact. Compact voices use less storage and may run faster, but their speech quality is lower. The list shows each voice's status and Samsung's reported package size. Sizes are retrieved in the background and cached for one day.

The list identifies installed voices using names embedded in Samsung's package where available, such as Amy Green, Stephanie, Julia, and Lisa. Samsung's own locale remains authoritative; for example, Julia is listed as US English even when her accent may sound different to some listeners.

Packages which cannot generate smooth live speech in real time are not offered. This currently excludes the original and Galaxy S24 Indian premium packages, plus the Galaxy S24 versions of Stephanie and John Lano. The compact Indian voice and the compatible original-generation Stephanie and John Lano voices remain available.

Select one voice, or use the standard Control and Shift selection keys to select several. Available actions are:

  • Download or update: downloads selected packages directly from Samsung, one at a time.
  • Remove: removes selected installed voices. A shared engine is removed only when no remaining voice needs it.
  • Play sample: speaks a local sample using one selected installed voice without changing NVDA's active synthesizer.
  • Stop sample: immediately stops sample playback.

Removed voices disappear from the running synth immediately. If you remove the voice currently speaking, Samsung switches to another installed voice first. The only installed voice cannot be removed while Samsung Galaxy Voices is active; switch synthesizers or install another voice before removing it.

Downloads continue in the background if the settings window is closed. Reopening Samsung Galaxy Voices shows the active voice as Downloading and keeps Download or update unavailable until it finishes. A focusable two-column status list reports the current voice, stage, batch position, progress, transferred size and download speed without moving your reading position as values change. Voice data is stored in NVDA's user-data folder, outside the add-on, so normal add-on updates preserve it.

Speech Settings

Voice, rate, pitch, and volume are available in NVDA's speech settings and synthesizer settings ring. Rate and pitch use Samsung's native controls. Rate 50 is Samsung's normal speed, with a progressively wider range above 50 for fast screen-reader use. Volume is applied through NVDA's audio path. During Say All, adjacent lines without a natural pause are passed to Samsung as one continuous utterance.

The Samsung Galaxy Voices panel also provides Playback buffering from 0 to 500 milliseconds, adjustable in 25 millisecond steps. Zero is the default and gives the fastest response. If live speech sounds grainy or breaks up on a slower or heavily loaded computer, increase the value in small steps until playback becomes stable. Higher values delay the beginning of each utterance but do not change the generated voice.

Playback buffering cannot repair a failed speech helper. If a helper fails or stops responding, the add-on discards it so later speech can use a working helper instead. The failed text is not replayed automatically. NVDA's log records the affected voice, engine version, failure stage, and recent helper activity without recording the requested text. These details are useful when reporting a problem.

Updates

The Samsung Galaxy Voices panel contains a Check for add-on updates setting with Never, Hourly, and Daily choices. Daily is the default for new installations. Check Now performs an immediate manual check. Update files and their manifests must pass cryptographic signature, package identity, version, size, and SHA-256 checks before NVDA will install them.

This schedule controls add-on updates. Voice packages are updated only when the user selects Download or update in the voice manager.

Updating Older Samsung Add-ons

If both Samsung Galaxy Voices and Samsung TV Voices are installed with versions older than Galaxy 1.1.5 and TV 1.0.4, their update buttons may check or install the other add-on. Download the latest .nvda-addon package from each project's GitHub Releases page, install both through NVDA's add-on manager, and restart NVDA. You do not need to remove or download your installed voices again. After this one-time update, each panel checks only its own add-on.

Changes in 1.1.3

  • Reduced the work needed to cancel interrupted characters in compatible premium engines, helping warm helpers remain available during rapid typing and navigation.

  • Fixed a completion-message race during rapid speech requests and interruptions.
  • Kept successfully completed helpers available when an interruption arrives at the same moment speech finishes.
  • Stopped restarting a working helper when Samsung successfully processes text that produces no spoken audio.
  • Limited helper accumulation during slow interruptions and closed obsolete helpers after voice changes or shutdown.
  • Stopped failed requests from leaving NVDA waiting indefinitely for speech to finish.
  • Added bounded helper diagnostics to NVDA's log to help investigate intermittent failures.

Changes in 1.1.2

  • Fixed automatic add-on updates that could remain pending and fail to replace the installed version.

  • Made failed voice downloads announce the affected voice and the specific package file that could not be installed.

Changes in 1.1.0

  • Added host support for the newer engine format and reliable interruption without undocumented memory access.
  • Improved catalogue loading by retrieving package details concurrently while keeping network work outside NVDA's user-interface thread.
  • Organised installed voices into generation-specific folders and added automatic migration for existing installations.
  • Removed the exact faulty original-generation Indian premium package while retaining the compact Indian voice.
